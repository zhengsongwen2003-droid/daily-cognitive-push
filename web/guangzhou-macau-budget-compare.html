Day 1：惠州 → 广州，老城和夜景

上午

惠州出发，到广州后先寄存行李

如果车次合适，优先到广州东；如果到广州南，就坐地铁2号线进市区。酒店建议订长寿路、黄沙、文化公园、北京路或公园前。

交通12306买票广州地铁进城

11:00

陈家祠

怎么去：地铁到陈家祠站，出站步行。

玩多久：1-1.5小时。

必打卡：正门牌坊、聚贤堂、屋顶陶塑、木雕砖雕灰塑。这里适合看岭南建筑细节。

低门票出发前查开放

中午

永庆坊 → 荔枝湾涌 → 上下九

怎么去：陈家祠到永庆坊可短途打车，或地铁到长寿路/黄沙后步行。

必打卡：恩宁路骑楼、永庆坊街区、荔枝湾涌、上下九骑楼街。

吃什么：艇仔粥、肠粉、云吞面、牛杂、双皮奶。人均40-70元。

下午

沙面岛

怎么去：从黄沙/文化公园附近步行或短途打车。

玩多久：1-1.5小时。

必打卡：沙面大街、沙面堂外观、白天鹅宾馆外观、珠江边。这里适合拍照和散步。

晚上

花城广场 + 广州塔外景

怎么去：地铁到珠江新城、花城大道或海心沙一带。

必打卡：花城广场、海心沙、广州塔夜景、珠江新城中轴线。

省钱建议：不登广州塔，外景已经很好看；晚餐吃简餐，人均50-80元。

Day 2：广州 → 珠海 → 澳门

早上

广州南站 → 珠海站

建议买9:00-10:30之间广州南到珠海的车，到珠海后先去拱北/青茂附近酒店寄存行李。

住拱北更顺澳门当天往返

过关

拱北或青茂口岸 → 澳门

住拱北附近就走拱北口岸，住青茂附近就走青茂口岸。节假日预留1小时以上，普通日也建议留30-60分钟。

提醒：带身份证、港澳通行证和有效澳门签注；口岸开放时间出发前再确认。

上午

议事亭前地 → 玫瑰堂 → 大三巴 → 大炮台

怎么去：过关后从关闸坐公交到新马路/议事亭前地一带，现场看站牌或地图。

必打卡：议事亭前地葡式碎石地、玫瑰堂外观、大三巴正面、大炮台俯瞰老城。

吃什么：葡挞、猪扒包、咖喱鱼蛋、牛杂。人均60-120元。

下午

官也街 + 龙环葡韵外观

怎么去：从新马路/亚马喇一带坐公交去氹仔，或两人短途打车分摊省时间。

必打卡：官也街、地堡街、龙环葡韵外观。

吃什么：葡挞、甜品、猪扒包、手信试吃。伴手礼先看价格，别冲动买。

傍晚

威尼斯人 + 伦敦人 + 巴黎人外观

怎么去：官也街到威尼斯人可步行、公交或短途打车。

必打卡：威尼斯人大运河购物中心、伦敦人外立面、巴黎人铁塔外景。

不建议：贡多拉、太贵餐厅、赌场区长时间停留。晚上回珠海吃饭更省。

晚上

澳门 → 珠海，住拱北附近

从路氹一带坐公交或酒店穿梭巴士回关闸，再过关回珠海。晚餐回珠海吃，粥粉面、烧腊饭、商场套餐都更稳，人均40-80元。

Day 3：珠海轻松收尾 → 惠州

上午

拱北 → 情侣路 / 城市阳台 / 珠海渔女

怎么去：从拱北打车或公交到情侣路一带。两个人打车分摊可以接受，省体力。

必打卡：城市阳台、香炉湾沙滩、珠海渔女、情侣路海景。

中午

日月贝 / 野狸岛

怎么去：从珠海渔女附近沿海边继续走，或短途打车。

必打卡：日月贝外观、野狸岛海边视角。

午餐：日月贝、扬名广场或拱北附近简餐，人均40-70元。

下午

取行李，返程回惠州

第三天不要排太满。根据12306选最合适路线回惠州，优先留出60-90分钟机动时间。

住宿推荐

广州第1晚

长寿路 / 黄沙 / 文化公园 / 北京路 / 公园前

最推荐：长寿路或黄沙。去陈家祠、永庆坊、上下九、沙面都顺，晚上吃东西方便。

预算：经济型酒店300-400元/晚，两人平摊人均150-200元。

下单关键词：近地铁、可寄存行李、独立卫浴、近两年装修、评分4.5以上。

珠海第2晚

拱北口岸 / 青茂口岸 / 珠海站附近

最推荐：拱北口岸附近。去澳门、回珠海吃饭、第三天返程都方便。

预算：经济型酒店280-420元/晚，两人平摊人均140-210元。

避坑：不要住离口岸太远的便宜房，也不建议住澳门。
